## Escape hatches and ranked retained boundaries

Python matching-line recipe:
`cast\(|# type: ignore|# ty: ignore|\bAny\b|# noqa`.
**4 -> 4**: exactly one noqa: E402 in each of bench-short.py, perf-gate-local.py,
perf-gate-report.py and trace-phases.py. Each establishes its local scripts import
path before importing the package entry point. These suppress import-order style,
not type errors. No casts, type ignores or explicit Any words were found.
Do not call the largely unannotated code fully typed because this counter is low.

1. **Registry/TOML boundary (incomplete model).** crates-io curl returns object,
   checks HTTP status, keeps raw non-JSON/404 text, and preserves None for absent
   crates. CratesClient.github_configs rejects a non-dict envelope and maps absent
   or non-list github_configs to []; list elements are trusted to the service
   schema although annotated list[dict]. Consumers then use config.get to decide
   whether publishing trust exists. A malformed list could violate the annotation;
   no evidence establishes that crates.io produced one. Element validation or a
   parsed configuration record would need an explicit malformed-response policy,
   not an annotation fed by Unknown. No live API, token read or publish executed.
2. **Benchmark verdict records (gradual shapes).** bench.design.checked rebuilds
   the declared schedule; stats.validate rejects missing/invalid durations, empty
   restores and cache faults; verify_pairs preserves incomplete/None distinctions
   before significance calculations. report.load marks legacy results descriptive.
   Machine snapshots contain dictionaries plus optional labels; do not flatten
   them into numeric dictionaries or turn unavailable metrics into zero.
3. **Resource/module invariants (retained).** sccache assigns server_log before
   constructing server, and teardown checks server is not None before closing its
   log. renderer_from loads a staged .py instrument; file-spec/loader fallibility
   remains an assumption rather than a new assertion changing exception behavior.
   rmtree chooses onexc versus onerror by Python version; a union kwargs warning
   is not proof the executing version calls the wrong overload. Subprocess groups,
   deadlines, cleanup and missing-tool behavior are untouched.
4. **Shell boundaries.** Bash has string/numeric guards rather than these Python
   typing candidates. with-test-resources validates positive integers before base-10
   arithmetic and preserves unlimited, Windows and fallback states. require-ci-green
   requires success for each exact named job and fails closed on missing/pending
   status. Retain shellcheck SC2016 suppressions for child-shell evaluation (three),
   and SC2086 for deliberate compiler/tool/target-list splitting (six). Bash syntax
   checks cover all 16 scripts; no ShellCheck or embedded-heredoc type check ran.
